# Cloud Computing Reflection

Cloud computing has become an important part of my daily life because I use many online services for communication, learning, and entertainment. Three cloud services that I use regularly are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of Software as a Service (SaaS) because it allows me to store, manage, and access my files through a web browser without installing complex software. It uses the Public Cloud deployment model because it is available to anyone with a Google account.

Facebook Messenger is also a Software as a Service (SaaS). It allows users to send messages, make voice and video calls, and share files through the internet. Like Google Drive, it uses the Public Cloud because millions of users access the same cloud infrastructure.

Canva is another Software as a Service (SaaS). I use it to create presentations, posters, and other school projects. Since Canva is available online to users around the world, it also uses the Public Cloud deployment model.

Version control is very important in cloud projects because it helps developers track every change made to files. If a mistake happens, previous versions can easily be restored. Git and GitHub make teamwork more organized by allowing multiple people to work on the same project without overwriting each other's work. They also provide a history of changes, making collaboration easier and reducing errors. As an IT student, I believe learning Git and GitHub is an essential skill because they help manage projects efficiently and support modern cloud computing development.
